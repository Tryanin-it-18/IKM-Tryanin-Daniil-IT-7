## Условие № 1

`m(a,b)` — минимум; `M(a,b)` — максимум. Допускается произвольная вложенность и положительные целые аргументы. Пример: `M(15,m(16,8))` → `15`. Расчёт выполняется двумя *собственными* стеками на односвязных списках. Если в учебной формулировке `М` напечатана кириллицей, программа также принимает кириллическую заглавную `М`.

## Условие № 17

Формат входного файла: `M` (1–999), затем M строк, каждая с количеством соседей `n_i`, количеством писем `l_i` и `n_i` номерами соседних гнёзд. Нумерация гнёзд начинается с 1, граф должен быть корректным связным деревом.

В решении тритон начинает от гнезда № 1, раздаёт все письма адресату при первом посещении, а заканчивать обход разрешено в любой вершине. Посещения без выдачи писем считаются извинениями. Если писем нет вовсе, ответ — 0. Это согласуется с примером из задания (ответ 2).

Алгоритм оставляет только необходимые для доставки ветки дерева; все их рёбра проходят дважды, кроме пути до самого далёкого адресата, который можно пройти однократно. Сложность O(M) после O(M²) проверки симметрии списка соседей в небольшом ограничении M<1000.

## Состав проекта

- `main.py` — циклическое меню.
- `structures.py` — собственные классы стека и дерева.
- `task1.py` — обработка вложенных функций через стек.
- `task17.py` — чтение дерева из файла, поиск минимума извинений и запись ответа в выходной файл.
- `examples/` — входные файлы.
- `tests/` — проверочные тесты.

## Ограничения

В задании № 1 принимаются только положительные целые числа, без пробелов и арифметических знаков. В задании № 17 ожидается правильный текстовый файл в UTF-8. Некорректные данные вызывают понятную ошибку и не завершают меню. Сторонние библиотеки для динамических структур не применяются.
